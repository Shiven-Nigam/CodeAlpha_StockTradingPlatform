# 📈 Stock Trading Platform

A console-based **Stock Trading Platform** developed in Java as part of the **CodeAlpha Java Programming Internship**.

The application simulates basic stock market operations, allowing users to view available stocks, buy and sell stocks, manage their portfolio, and track their account balance.

---

## 📌 Project Overview

The Stock Trading Platform is a simple Java application designed to demonstrate how a stock trading system can be implemented using **Object-Oriented Programming (OOP)** concepts.

Users can:

- View available stocks
- Buy stocks
- Sell stocks
- Deposit money
- Withdraw money
- View account balance
- View portfolio holdings
- Track stock quantities
- Calculate portfolio value

This project is intended for **educational purposes** and does not perform real stock market transactions.

---

## ✨ Features

### 👤 User Management

- Create a user account
- Store user name
- Maintain account balance
- Deposit funds
- Withdraw funds

### 📊 Stock Management

- Store stock symbols
- Store stock names
- Maintain stock prices
- Display available stocks
- Buy available stocks

### 💼 Portfolio Management

- Maintain user's stock holdings
- Buy stocks and add them to the portfolio
- Sell stocks from the portfolio
- Track the quantity of each stock
- Calculate portfolio value

### 💰 Trading Operations

The platform supports:

- Buying stocks
- Selling stocks
- Checking available balance
- Updating balance after transactions
- Viewing portfolio details
